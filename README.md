A dedicated study guide and development reference repository for candidates preparing for the **Android ATC Flutter Certified Application Developer (AFD-200) Certification Exam**.

---

## Exam Overview

The Flutter Certified Application Developer certification validates knowledge of Dart programming and the development of cross-platform mobile applications using Flutter, including user interfaces, navigation, integrations, testing, and deployment.

- **Exam Format**: Closed-book, multiple-choice examination covering theoretical and practical Flutter development concepts.
- **Target Audience**: Flutter developers, mobile application developers, software programmers, and candidates developing Android and iOS applications.
- **Prerequisites**: No mandatory course attendance or formal prerequisites. The mapped Flutter Application Development course begins with Dart fundamentals.

---

## Core Exam Domains & Knowledge Areas

The following knowledge areas are organized from Android ATC's AFD-200 course outline; they are not presented as a separately published official exam-domain blueprint.

### 1. Dart Programming Fundamentals

- Dart syntax, variables, data types, operators, conditional statements, and loops.
- Functions, return types, variable scope, and object-oriented programming.
- Classes, constructors, inheritance, abstract classes, and Dart project structure.

### 2. Flutter Framework, Widgets, and Navigation

- Flutter SDK setup, project creation, Android Studio, emulators, and device testing.
- Widget fundamentals, Material Design, layouts, stateful and stateless widgets, and UI components.
- App navigation, routing, screen transitions, and data exchange between screens.

### 3. Firebase and Location-Aware Applications

- Firebase integration, application configuration, and user authentication.
- Firebase Realtime Database and Cloud Firestore fundamentals.
- GPS, Google Maps integration, API keys, map markers, and location permissions.

### 4. Application Testing and Publishing

- Flutter application testing, test environments, feedback, and usability evaluation.
- Debugging and reviewing application behavior across mobile platforms.
- Publishing Flutter applications to Google Play and the Apple App Store.
